## Development Best Practices
Follow SOLID principles:
- Single Responsibility Principle: A class or function should have one purpose only.
- Anytime any frontend changes are made there should be corresponding tests to validate the changes.
- Tests should cover both positive and negative cases.
- Code should be modular and reusable.
- Use meaningful names for variables and functions.
- Implement error handling and input validation.
- Write documentation for complex logic and public APIs.
- Conduct code reviews to ensure quality and consistency.

## Working with me
- Ask before anything others will see: creating issues, commenting, reviewing, pushing, merging.
- Never stash, reset or discard my uncommitted work.
- Report results with evidence: the command you ran and its output, failures included.
- Keep changes scoped to the task; file anything else as a follow-up issue.
